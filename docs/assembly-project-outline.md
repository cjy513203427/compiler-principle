# 独立汇编专题规划

状态：内容规划，尚未创建新项目。当前仓库仍是编译原理笔记；附录只负责随书查阅，原有演示与笔记保留。

## 读者与目标

照顾学过简单高级语言、但未学过汇编的读者，也让学过 8086 的读者能够复习并过渡到现代环境。读者最终应能解释一小段程序如何改变寄存器、标志、内存与执行位置，再读懂简单函数的编译结果。

贯穿方式是“高级语言表达意图 → 拆成机器动作 → 对照汇编 → 单步修改状态”。每个新名词先用小例子建立含义，再出现缩写、寄存器名或平台规则。

## 建议顺序

| 单元         | 先解决的疑问                                         | 交互练习                                                          |
| ------------ | ---------------------------------------------------- | ----------------------------------------------------------------- |
| 机器模型     | CPU、寄存器、内存各负责什么？变量和值存在哪里？      | 先用少量自命名格子执行赋值和加法，追踪读写                        |
| 位与数值     | 一个字节有多大？地址和值有什么区别？有符号如何解释？ | 同一组位切换二进制、十六进制和整数解释                            |
| 体系关系     | 8086、x86、80386、x86-64 分别指什么？                | 架构时间线与 16/32/64 位寄存器窗口对照；区分语法、模式、OS 和 ABI |
| 赋值与运算   | MOV 为什么不清空源？ADD 改了哪些状态？               | 高级语言与指令一一核对，修改参数、检查标志                        |
| 内存与寻址   | 方括号表示什么？变量、指针和数组如何对应地址？       | 用真实字节布局解释数组下标和小端顺序                              |
| 判断与循环   | if / while 怎样变成比较与跳转？                      | 跟踪标志产生、条件判断和回边；比较 signed / unsigned              |
| 函数与栈     | 返回地址与返回值有何区别？局部变量放哪里？           | 先建立调用/返回模型，再引入真实栈帧与保存约定                     |
| 现代调用约定 | 为什么同一个函数的参数寄存器不同？                   | 将 Windows x64 与 System V AMD64 放在各自清楚标记的环境里对照     |
| 阅读编译结果 | 为什么变量、MOV、分支或栈帧会消失？                  | 简单 C 函数的 O0 / O2 对照，区分语义等值与性能推测                |

8086 的分段、中断、DOS 环境另设历史实践单元，明确执行环境，不将段:偏移公式直接沿用到现代 64 位示例。主线不要求先把一套历史操作系统与完整指令表学完。
