# 界面语言（中文 / English / Deutsch）

## 地址

| 语言 | 地址 | `<html lang>` |
| ---- | ---- | ------------- |
| 中文 | `/?lab=lex`（原样） | `zh-CN` |
| 英文 | `/en/?lab=lex` | `en` |
| 德文 | `/de/?lab=lex` | `de` |

所有实验继续通过 `?lab=…` 查询参数路由，只在路径前增加 `/en/` 或 `/de/` 语言前缀；已有中文链接完全不变。左侧目录底部的语言切换保留当前实验、源码、步骤和优化/寄存器/代码生成/汇编参数，所以分享链接和当前状态可以直接切换语言查看；手机端先打开目录切换。Vite dev / preview 会将 `/en/`、`/de/` 回退到同一个 `index.html`。

## 机制

- 中文是源语言，原文保留在代码里：普通字符串写 `T('中文')`，带变量写 `T('第 {#0} 行', line)`；JSX 中夹杂强调或代码节点时写 `Tx('一段代码，{#0}如何变成{#1}', <br />, <span>…</span>)`。占位符用 `{#i}`，译文可以自由调整占位符顺序。
- 译文存放在 `src/i18n/catalog/en.json` 和 `de.json`，键为中文原文，按源码顺序排列，方便对照审阅。
- `src/main.tsx` 先根据 URL 确定语言并按需加载对应目录（中文页面不加载任何目录 JSON），再动态导入 `src/bootstrap.tsx`。语言在页面生命周期内固定，因此模块可以在导入时直接调用 `T()`。
- 编译器层（`src/compiler/**`）输出的步骤说明、诊断和运行时报错同样使用 `T()`。如果多个模块需要对比同一条错误消息（如 VM 与 x86-64 模拟器的除零/溢出报错），两边调用相同的 `T('…')` 即可在三种语言下保持一致。
- 私人笔记保存在浏览器本地 `localStorage`（按实验 ID 存储，不依赖语言），切换语言不会丢失已有笔记，也不会编码进分享链接。

## 新增或修改中文文本

1. 照常写中文，但包在 `T(…)` 或 `Tx(…)` 里（第一个参数必须是静态字符串字面量或无插值模板字符串）。
2. `npm run i18n -- todo [路径片段]` 列出尚未翻译的条目：hash、文件行号、占位符对应代码与中文原文。
3. 把译文写进 TSV 文件，每行 `hash:中文开头<TAB>英文<TAB>德文`（`\n` 会被解码为换行；行尾有空格时在末尾加 `<TAB>|`）。正则说明等需要字面 `\n` 的条目，请直接编辑目录 JSON。
4. `npm run i18n -- merge 文件.tsv` 合并；`npm run i18n -- check` 检查。
5. `node scripts/i18n-scan.mjs -v` 列出没有包进 `T()` / `Tx()` 的中文字面量。目前剩下的只有原书目录 URL 与章节文件名，它们是指向中文原书的链接，按原样保留。
6. `npm test` 会通过 `src/i18n/i18n.test.ts` 与 `src/content/locales.test.ts` 检查漏译、多余条目、占位符、残留中文、首尾空格一致性，并在英文与德文环境下重跑全部预设：结果须与中文一致（预设里被翻译的只有注释），编译器输出与内容导出中不得残留中文。

不要用 `T()` 的返回值做程序逻辑判断（例如与中文字面量比较）；需要分支时保存稳定的英文 ID，显示时再翻译。同一中文在不同场景需要不同译法时（如名词“输出”与动词“产生输出”），使用不同的中文原文。

## 图形与排版

英文、德文通常比中文更长：

- 弹性布局里的行号、标记等不应被长译文挤压（`flex-shrink: 0`）；窄卡片中的德语长复合词允许断行（`overflow-wrap: anywhere; hyphens: auto`）。
- SVG 定宽标签按字宽估算（与 `maxChars` 相同的思路），放不下时改用更短的写法或截断，例如控制流图在窄屏上把“B0 · 本步”简写为“B0”。中文能放下时显示不变。
- `tests/i18n.spec.ts` 在桌面端和手机端、英文和德文下检查每个实验的首步、最终结果、原理笔记与复述自测，以及首页、笔记、来源与汇编附录：无残留中文（含 CSS 伪元素、无障碍属性与输入框内容）、无 `[i18n] missing` 警告、无横向溢出、无 SVG/HTML 文字溢出或重叠、站内链接保持当前语言，并验证语言切换保留实验与步骤。

## 翻译约定

- 英文使用标准编译原理术语（Lexical Analysis、Recursive Descent、AST、TAC、CFG、Dominance Frontier、SSA、SCCP、Live Variables、Interference Graph、Graph Coloring、Linear Scan、List Scheduling、Peephole Optimization、Available Expressions、CSE、LICM、Tri-color Marking、Tree Tiling、Maximal Munch、Interprocedural Analysis、Inlining）。
- 德文使用 `du`，遵循德语计算机科学教材习惯，保留业界通用的英文术语（Token、AST、CFG、SSA、NFA、DFA、IR、Stack、Heap、Phi / φ、Register、ABI、Inlining 等）；数字统一用小数点，避免与列表逗号混淆。
- 原书《编译原理实战课》（宫文学）无英德译本，在英德页面注明中文原书（Chinese original / chinesisches Original），并保留原书章节链接及 LLVM / Cornell / CMU / Intel SDM 等英文参考链接。
