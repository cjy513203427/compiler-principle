# 内容与后续维护

## 本版范围

本项目把原书核心概念与现代语言实现主题串成三十个实验。第 06 讲的 IR / P-code 概念支撑自定义教学栈机，第七个实验是控制流图，第八个实验是条件常量传播与活跃变量数据流分析，第九个实验是支配关系、自然循环和迭代 φ 候选。第十个实验回到第 02 讲：由词法规则构造 NFA，经子集构造得到 DFA，再做最长匹配扫描，并与原书的 NFA 回溯匹配对照。第十一个实验对应第 03 讲：产生式、左递归与改写、FIRST / FOLLOW、LL(1) 分析表和表驱动解析；第十二个实验对应第 03 讲后半：LR(0) 项目集、SLR(1) 表与移进 / 规约。实验 13–15 补充标量 SSA 构造、DFA 最小化与 SSA 消除；实验 16 使用专用函数方言观察调用帧；实验 17、18 回到第 08 讲的寄存器分配、指令排序与窥孔优化；实验 19 补第 07 讲的公共子表达式与循环外提，实验 20 补第 32 讲的垃圾收集；实验 21–30 进一步补齐指令选择（08 / 16）、SSA 上的稀疏优化（06 / 07）、内联与逃逸分析（07 / 15）、面向对象虚表（38）、闭包环境捕获（05 / 39）、无栈协程状态机（34）、泛型擦除与单态化（37）、V8 隐藏类与内联缓存（21）、并发 GC 写屏障（32）与 Sea of Nodes 去优化（14 / 15）。实验 10–30 的原理笔记均先用“一步一步读懂”从已做过的实验讲起，再给小结；后续新实验沿用这种写法，每一步只引入一个新概念。第 18 讲只作为延伸入口。控制流概念另核对 LLVM 官方教程第 5 章；数据流、支配关系与 SSA 参考 Cornell CS 4120 / CS 6120，自然循环参考 LLVM 术语说明，调用栈参考 Cornell 与《Crafting Interpreters》作者实现。采用本项目的严格 bool 条件与安全整数语义。

控制流图回放状态取自真实 VM 快照；数据流分析使用抽象事实与传递函数，不借用运行结果。跨块优化已接入传播、折叠、分支简化、不可达块清理和活跃性驱动的无用复制清理，异常与输出顺序保留。旧版本笔记仍使用版本 1，新增 cfg / dataflow 条目不丢失之前的内容与复习标记。

第十三个实验 `/?lab=ssa` 从支配关系继续：按原始结构图的活跃性裁剪 φ，沿支配树进行版本栈重命名，校验唯一定义、支配与 φ 前驱完整性，再用 SSA 解释器与原始 VM 对照输出、异常顺序。2026-11-21 核对 Cornell SSA 讲义与 LLVM φ 语义，未请求原书。两种执行预算的计步单位不同，任一超限就不判定等价。构造与执行各记录前 240 步，最终结果保留。范围限标量局部变量，不涉及内存 SSA、SSA 消除或 LLVM 后端；旧笔记版本 1 继续兼容。

第十四个实验 `/?lab=minimize` 沿用词法规则输入，先按获胜规则分组，再细化至不动点。补入可达 Dead 处理缺失转换，导出扫描器时省略失败类与边，空语言保留入口。可查询原始状态对的最短区分后缀，并独立校验所有支持后缀的获胜规则以及当前输入的 Token 与首次失败位置。2026-11-21 核对 Cornell DFA 最小化与词法动作讲义；7 个可编辑预设，规则限制与实验 10 相同，不把子集构造超限的残图当成完整 DFA。表填充算法与短输入枚举用于独立测试。没有 Hopcroft 或 NFA 最小化。

第十五个实验 `/?lab=outssa` 接通 SSA 到原 VM 的转换链：按边收集 φ 复制，根据实际前驱/后继关系选择前驱末尾、后继入口或关键边拆分；调度并行复制、保存环上的旧值后重建普通 IR 与字节码。保留版本名但不再保持单赋值性质，没有复制合并或寄存器分配。主程序 7 个预设；独立复制小实验有 4 个预设与 500 字符限制，不写入分享 URL。原始 VM、SSA 解释器与消除后 VM 对照输出及错误，任一超限时不判定等价。2026-11-21 核对 Cornell 与 CMU 讲义，未请求原书。

第十六个实验 `/?lab=functions` 提供专用函数方言，复用现有扫描器与安全整数运算，先登记签名，再检查词法作用域、实参和返回路径，直接生成函数字节码。支持 int / bool 单值返回、按值传参、递归、相互递归、分支与循环；顶层变量只是入口帧局部变量，函数不能读取它们。记录独立局部变量表、每帧操作数栈、返回位置与真实 CALL / RETURN 事件。10 个预设覆盖正常结果、求值顺序、异常、作用域和上限。最多 2000 字符、24 个函数、8 个形参、32 个活动帧（含入口）和 2000 条执行指令，保留前 400 个状态及最终现场。没有跨过程优化、闭包、异常展开或真实 ABI。2026-11-21 核对 Cornell Calling Conventions 与《Crafting Interpreters》作者实现，未请求原书。

第十七个实验 `/?lab=regalloc` 在未优化的原始三地址代码上做寄存器分配，K 为 2–8，可选图着色（Chaitin 简化 + Briggs 乐观着色，循环深度加权代价，复制偏好）或线性扫描（Poletto & Sarkar 整区间）。溢出值插入 load / store 后重新分析，最多 16 轮；最终分配经独立活跃性检查，再由教学寄存器机执行并与原 VM 对照。K 与算法写入分享 URL 并在读取时校验。6 个预设；单元测试覆盖全部 Mini C 预设与 40 个固定种子随机程序的全部 K × 算法组合。没有复制合并、区间拆分、重新物化、调用约定或机器码。2026-11-22 从本地缓存重读第 08 讲寄存器分配一节，核对 Cornell CS 4120 寄存器分配讲义。

## 2026-11-25 进阶实验补充（实验 21–26）与章节核对

在 `feat/advanced-compiler-labs` 分支补充六个进阶实验，沿用“一步一步读懂”、独立计算核对、有界输入与本地笔记约定；并于同日通过 `scripts/fetch-source.mjs` 单页串行缓存并核对原书第 15、34、38、39 讲（已加入脚本允许列表，缓存不提交）：

- **实验 21 指令选择 `/?lab=isel`**（Mini C，对应第 08 / 16 讲，本地缓存复核）：在基本块内折叠单使用者临时变量为表达式树，比较 CISC（含 `LEA` 融合寻址与 `MADD`）贪心最大吞噬、自底向上动态规划（BURS 思路）、RISC Load-Store 与逐条直译的代价，并执行四个目标版本与原 VM 核对。
- **实验 22 SSA 上的优化 `/?lab=ssaopt`**（Mini C，对应第 06 / 07 讲，本地缓存复核）：直接在实验 13 的 SSA 上运行 Wegman–Zadeck 稀疏条件常量传播（CFG 边工作表 + SSA def-use 工作表）、平凡 φ 化简与保守 SSA 死代码消除（保留可能除零/溢出的未折叠算术），与原 VM 和优化前 SSA 三方核对。
- **实验 23 内联与逃逸分析 `/?lab=escape`**（独立结构体与函数方言，对应第 07 / 15 讲，2026-11-25 单页读取第 15 讲核对）：演示非递归单尾返回小函数内联如何将 `GlobalEscape` 对象转为 `NoEscape`，包含字段传递逃逸、递归 `ArgEscape` 与跨分支多对象别名保守处理，并通过标量替换（SROA）消除堆分配，三版本执行核对；边界明确不模拟多态内联、锁消除、部分逃逸分析（PEA）与基于推理的逆优化。
- **实验 24 面向对象与虚表分派 `/?lab=vtable`**（独立单继承类方言，对应第 38 讲，2026-11-25 单页读取核对）：构建前缀兼容对象布局（`+0 vptr` + 父到子字段）与虚函数表槽位覆写，追踪运行时 `vptr → vtable[slot]` 动态绑定与模板方法 `this` 回调，并做封闭世界 CHA + 精确类型去虚拟化对照；明确与静态绑定、多重继承指针偏移调整及接口表的边界。
- **实验 25 闭包与环境捕获 `/?lab=closure`**（独立嵌套函数方言，对应第 05 / 39 讲，2026-11-25 单页读取第 39 讲核对）：静态自由变量分析区分栈局部变量与堆上装箱 Cell（Upvalue），展示创建栈帧弹出后 Cell 持续存活、同作用域共享 Cell 与多级捕获转发，并与独立链式词法解释器核对；明确未涵盖延迟求值、函数复合类型逆变/协变检查与尾递归转循环。
- **实验 26 协程与状态机改写 `/?lab=coroutine`**（独立无栈协程方言，对应第 34 讲，2026-11-25 单页读取核对）：对非对称无栈同步协程的线性化 IR 做跨 `yield` 活跃变量分析，将跨挂起点变量提升进协程帧、将临时变量留在临时调用栈，生成可读的 `switch (frame->state)` 状态机代码并与独立原生生成器核对；明确不模拟有栈 Side Stack、Go 可增长栈序曲、libco 共享栈、对称 channel 或异步 IO 调度器。
- **实验 27 泛型编译：擦除与单态化 `/?lab=generics`**（独立泛型方言，对应第 37 讲，2026-11-25 单页读取核对）：同时跑通类型擦除（Java 路线，自动插入 `box / checkcast / unbox`，检测擦除重载签名冲突）与单态化（C++ / Rust 路线，零装箱特化展开），演示泛型不变性（`Box<Cat>` 不可赋给 `Box<Animal>`），并与独立类型化参考解释器核对。
- **实验 28 隐藏类与内联缓存 `/?lab=inlinecache`**（独立动态对象方言，对应第 21 讲，2026-11-25 单页读取核对）：复现 V8 Hidden Class（Shape）属性添加顺序转移树与对象紧凑槽位，追踪每个 `obj.prop` 调用点的 IC 状态（未初始化 → 单态 → 多态 ≤4 → 超态），并与独立字典模式解释器核对输出与访问代价。
