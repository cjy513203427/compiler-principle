# 内容与后续维护

## 本版范围

本项目把第 02、03、04、06、07 讲中的基础机制与补充资料串成十六个实验。第 06 讲的 IR / P-code 概念支撑自定义教学栈机，第七个实验是控制流图，第八个实验是条件常量传播与活跃变量数据流分析，第九个实验是支配关系、自然循环和迭代 φ 候选。第十个实验回到第 02 讲：由词法规则构造 NFA，经子集构造得到 DFA，再做最长匹配扫描，并与原书的 NFA 回溯匹配对照。第十一个实验对应第 03 讲：产生式、左递归与改写、FIRST / FOLLOW、LL(1) 分析表和表驱动解析；第十二个实验对应第 03 讲后半：LR(0) 项目集、SLR(1) 表与移进 / 规约。实验 13–15 补充标量 SSA 构造、DFA 最小化与 SSA 消除；实验 16 使用专用函数方言观察调用帧。实验 10–16 的原理笔记先用“一步一步读懂”从已做过的实验讲起，再给小结；后续新实验沿用这种写法，每一步只引入一个新概念。第 18 讲只作为延伸入口。控制流概念另核对 LLVM 官方教程第 5 章；数据流、支配关系与 SSA 参考 Cornell CS 4120，自然循环参考 LLVM 术语说明，调用栈参考 Cornell 与《Crafting Interpreters》作者实现。采用本项目的严格 bool 条件与安全整数语义。

控制流图回放状态取自真实 VM 快照；数据流分析使用抽象事实与传递函数，不借用运行结果。跨块优化已接入传播、折叠、分支简化、不可达块清理和活跃性驱动的无用复制清理，异常与输出顺序保留。旧版本笔记仍使用版本 1，新增 cfg / dataflow 条目不丢失之前的内容与复习标记。

## 2026-11-21 内容检查与后续顺序

学习衔接已补三条路线：六站基础流程、四站词法/文法进阶、六站程序表示/调用。原理页提供建议前置与后续实验，内容维护在 `src/content/learning.ts`；入口只作建议，不限制直接访问。函数实验使用独立输入，不把跨过程调用送入现有优化器。

站内切换现在分别保留已运行输入与未运行草稿，避免在 Mini C、自动机、文法等输入之间切换时丢失编辑。未运行内容不会进入旧结果或分享 URL，也不会被专用实验的默认预设覆盖。草稿只保留在当前页面内存；刷新、URL 恢复与私人笔记导出仍只遵循各自原有范围。

下一轮按接通现有学习链路的收益排序。基础 SSA 消除已在实验 15 完成，专用函数与调用栈已在实验 16 补入，下表列出仍未实现的部分：

| 顺序 | 补充主题 | 当前缺口与验收重点 |
| --- | --- | --- |
| 1 | SSA 上的优化与复制合并 | 实验 15 已将 φ 转回普通 IR 并接回原 VM。后续可讨论减少冗余复制或在 SSA 上做优化；现有优化器仍使用可变变量 IR，不应把基础消除称为已完成 SSA 优化器。 |
| 2 | 寄存器分配与代码生成（Register allocation / Code generation） | 已有活跃性分析和汇编速查，但核心编译器没有机器码后端。先观察值的活跃区间、有限寄存器与溢出到栈，再建立实际 IR 到目标指令的映射；先明确目标整数语义与调用约定。现有手写模板与 GCC 固定文件不能冒充 Mini C 的编译输出。 |
| 3 | 函数接入 IR 与跨过程分析 | 实验 16 已有真实函数编译与栈帧执行，但采用独立方言。后续需先建模调用的输出、异常及内存效果，才能接入现有优化链；不能直接把 CALL 当作普通纯表达式清理。 |

可选深化：

- **LR(1) / LALR**：在现有项目集上加入向前看符号，用已收录的 SLR 冲突文法对照；仍需如实报告真正有冲突的文法。
- **左公因子与错误恢复**：实验 11 已报告 LL(1) 冲突，尚无左公因子提取；各解析器目前停止于首个错误。补改写前后解析对照、错误位置与恢复过程，并继续限制步骤。
- **CSE 与循环优化**：现有优化主要是传播、折叠和清理。先补支持这些变换的分析，再考虑公共子表达式、循环不变量等；对输出、除零与溢出异常保持现有约定。
- **Hopcroft 最小化**：实验 14 的 Moore 式细化已覆盖教学目标，可增加另一算法并比较真实处理次数。保持等价类和 Token 语义一致，不能只换算法名称。

工程整理可另做主题代码拆分；不扩大当前本地运行范围，不创建云资源。每项新增实验都继续执行下方的验收要求。

第十三个实验 `/?lab=ssa` 从支配关系继续：按原始结构图的活跃性裁剪 φ，沿支配树进行版本栈重命名，校验唯一定义、支配与 φ 前驱完整性，再用 SSA 解释器与原始 VM 对照输出、异常顺序。2026-11-21 核对 Cornell SSA 讲义与 LLVM φ 语义，未请求原书。两种执行预算的计步单位不同，任一超限就不判定等价。构造与执行各记录前 240 步，最终结果保留。范围限标量局部变量，不涉及内存 SSA、SSA 消除或 LLVM 后端；旧笔记版本 1 继续兼容。

第十四个实验 `/?lab=minimize` 沿用词法规则输入，先按获胜规则分组，再细化至不动点。补入可达 Dead 处理缺失转换，导出扫描器时省略失败类与边，空语言保留入口。可查询原始状态对的最短区分后缀，并独立校验所有支持后缀的获胜规则以及当前输入的 Token 与首次失败位置。2026-11-21 核对 Cornell DFA 最小化与词法动作讲义；7 个可编辑预设，规则限制与实验 10 相同，不把子集构造超限的残图当成完整 DFA。表填充算法与短输入枚举用于独立测试。没有 Hopcroft 或 NFA 最小化。

第十五个实验 `/?lab=outssa` 接通 SSA 到原 VM 的转换链：按边收集 φ 复制，根据实际前驱/后继关系选择前驱末尾、后继入口或关键边拆分；调度并行复制、保存环上的旧值后重建普通 IR 与字节码。保留版本名但不再保持单赋值性质，没有复制合并或寄存器分配。主程序 7 个预设；独立复制小实验有 4 个预设与 500 字符限制，不写入分享 URL。原始 VM、SSA 解释器与消除后 VM 对照输出及错误，任一超限时不判定等价。2026-11-21 核对 Cornell 与 CMU 讲义，未请求原书。

第十六个实验 `/?lab=functions` 提供专用函数方言，复用现有扫描器与安全整数运算，先登记签名，再检查词法作用域、实参和返回路径，直接生成函数字节码。支持 int / bool 单值返回、按值传参、递归、相互递归、分支与循环；顶层变量只是入口帧局部变量，函数不能读取它们。记录独立局部变量表、每帧操作数栈、返回位置与真实 CALL / RETURN 事件。10 个预设覆盖正常结果、求值顺序、异常、作用域和上限。最多 2000 字符、24 个函数、8 个形参、32 个活动帧（含入口）和 2000 条执行指令，保留前 400 个状态及最终现场。没有跨过程优化、闭包、异常展开或真实 ABI。2026-11-21 核对 Cornell Calling Conventions 与《Crafting Interpreters》作者实现，未请求原书。

## 新实验验收

- 有一个可以修改的真实计算例子，以及一个能揭示误解的对照例子。
- 结果由计算得到；源码位置、状态与说明一致，回放可暂停和回退。
- 修改输入或配置后，停止旧回放并重建状态。
- 写明采用的语言语义、简化边界、参考章节和核对日期。
- 使用独立的预期结果验证算法，检查异常与优化是否保持可观察行为。
- 验证键盘、小屏幕和 reduced-motion，不依赖颜色传递唯一信息。
