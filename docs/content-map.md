# 内容与后续维护

## 本版范围

本项目把第 02、03、04、06、07 讲中的基础机制串成七个实验。第 06 讲的 IR / P-code 概念支撑自定义教学栈机，第七个实验扩展 if / else、while 和基本块控制流图，第 18 讲只作为延伸入口。控制流概念另核对 LLVM 官方教程第 5 章；采用本项目的严格 bool 条件与可变局部变量语义。

控制流图从生成的 IR 切分首指令与基本块，边来自条件跳转、无条件跳转和顺序执行。回放状态取自真实 VM 快照，支持嵌套、零次循环、未选分支、变量更新和回放上限。分支/循环程序保留原始 IR，尚未做跨块优化。旧版本笔记仍使用版本 1，新增 cfg 条目不会丢失之前的内容与复习标记。

下一步可以选择一个边界继续实现：

1. NFA / DFA 与子集构造：增加正则表达式输入和集合状态轨迹。
2. FIRST / FOLLOW 与预测分析：增加文法输入与冲突检测，不能只给固定结果表。
3. 跨块数据流分析：在已有 CFG 上迭代求解常量信息和活跃性，再讨论 SSA 与 φ；不能把直线代码优化器直接用于分支或循环。
4. 函数与调用栈：分清操作数栈、调用栈、栈帧与词法环境，再扩展闭包。

这些是尚未实现的候选，界面没有将其标记为完成。

## 新实验验收

- 有一个可以修改的真实计算例子，以及一个能揭示误解的对照例子。
- 结果由计算得到；源码位置、状态与说明一致，回放可暂停和回退。
- 修改输入或配置后，停止旧回放并重建状态。
- 写明采用的语言语义、简化边界、参考章节和核对日期。
- 使用独立的预期结果验证算法，检查异常与优化是否保持可观察行为。
- 验证键盘、小屏幕和 reduced-motion，不依赖颜色传递唯一信息。
