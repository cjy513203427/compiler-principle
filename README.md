# 编译手记

基于宫文学《编译原理实战课》的中文交互笔记。参考同级 `transformer-animation` 的学习方式：**先预测，改输入，单步核对，再用自己的话复述**。本项目独立实现，不依赖兄弟项目运行。

## 本地运行

需要 Node.js 22.12+（或更新的受支持版本）和 npm。

```sh
npm ci
npm run dev
```

打开终端显示的地址（默认 `http://127.0.0.1:5173`）。所有编译与执行发生在浏览器中，无后端、账号或 API Key。仅在本仓库交付，没有创建云资源或发布网站。

```sh
npm run check       # 类型检查、算法与状态测试、生产构建
npm run test:e2e    # 桌面与手机尺寸的浏览器测试，需要本机 Chrome
npm run preview    # 本地预览生产构建
```

浏览器测试使用 Chrome channel；未安装 Chrome 时，可安装 Chrome，或在 `playwright.config.ts` 移除 `channel` 并安装 Playwright Chromium。

## 教学语言

```c
int result = 2 + 3 * 4;
print(result);

int x = 10;
{
  int x = 20; // 内层声明遮蔽外层
  print(x);
}
print(x);
```

支持 `int`、`bool`，变量声明和赋值，`+ - * /`、一元负号、括号、语句块、`print`、`//` 单行注释。语句需要半角分号。只有 ASCII 标识符；`int`、`bool`、`print`、`true`、`false` 是保留字。

整数使用 JavaScript 安全整数，除法向零取整，溢出和除零报告运行时错误。无隐式类型转换。初始化表达式先分析，新绑定随后引入；同层不能重复声明，内层允许遮蔽。源码限制 2000 字符，括号/一元运算/语句块嵌套限制 64 层。

支持 `if / else` 和 `while`，条件必须是 `bool`，主体必须用花括号。比较运算支持 `< <= > >= == !=`，算术优先于比较、比较优先于相等性。大小比较仅用于整数，相等性比较要求两侧类型相同。暂不支持 `break / continue`、逻辑短路、函数、字符串、浮点、闭包、对象与垃圾回收。IR 与字节码均为自定义教学格式，**不是 LLVM IR、JVM 或 CPython 的真实指令**，没有寄存器分配或机器码生成。

```c
int i = 1;
int sum = 0;
while (i < 4) {
  sum = sum + i;
  i = i + 1;
}
if (sum == 6) {
  print(sum);
} else {
  print(0);
}
```

第七个实验 `/?lab=cfg` 从原始 IR 划分基本块，再由虚拟机的真实执行快照生成按块回放的路径。图保留全部可能边，高亮本次实际经过的边；点击块可检查完整指令，前进/回退时变量与输出随快照更新。跳转使用生成的标签地址，不是写死的动画路线。

每次回放最多执行 2000 条字节码，避免错误循环阻塞界面。达到上限时明确显示暂停，**不代表已经证明程序不会终止**，暂停前的输出也不能用于判断完整行为等价。

## 算法与数据流

```text
source → tokenize → parse → analyze → generateIR → optimize → generateBytecode → execute
           tokens     AST     绑定/类型     TAC          TAC          栈式指令        快照
```

计算逻辑与 UI 分离，不使用 `eval` 或 `Function` 执行输入。每步状态来自真实扫描、构树、分析或执行。AST 回放展示最终树并高亮当时构建的节点，不伪装成增量生成的树。

直线代码沿用顺序传播与反向清理；**分支/循环已接入跨块优化**：先求解条件常量事实，再传播、折叠，最后依据可执行边删除不可达块，并在改写后的 CFG 上迭代活跃性，清理无用复制和标签。可能报错的未折叠算术仍然保留，输出与异常顺序不重排。三个开关分别控制表达式折叠、常量替换、分支/不可达与无用写入清理；分析本身不依赖开关，也不借用一次执行的结果。

第八个实验 `/?lab=dataflow` 展示原始 CFG 的分析：每次处理一个块，合并可执行前驱的 OUT，求出本块 IN / OUT，直到事实和边都不再变化。⊥ 是尚无信息，常量 c 是确定值，⊤ 表示不能确定唯一常量。循环可能让早期常量变成 ⊤；两条路径都赋 7 时仍可合并为 7。最后一步可选择任意块查看完整事实，也可查看原始结构图上的保守活跃变量集合。分析与执行快照清楚区分。

条件常量传播与活跃性均最多 200 轮；常量分析未收敛时保留原始 IR，不把未分析路径当成不可达。分析中间回放最多保留 240 次块处理，最终表始终展示完整分析结果，达到记录上限不会提前停止求解。实现为可变变量上的**稠密条件常量传播**，没有 SSA、φ、取值范围分析、循环展开或 LLVM 的稀疏实现。

页面实际运行原始版和优化版，比较当前程序的输出与错误；任一版本达到 VM 回放上限时，比较结果为无法判定。这个对照不等于一般性的语义等价证明，IR 指令数也不等于运行时间。

## 原书与访问限流

来源：[《编译原理实战课》](https://learn.lianglianglee.com/专栏/编译原理实战课)，作者宫文学。2026-11-16 顺序核对第 02、03、04、06、07 讲。本项目说明、图形、例子与代码独立编写，不打包原书正文和图片。第 18 讲仅列作后续延伸阅读，本次未核对。

控制流概念于 2026-11-16 补充核对 [LLVM 官方教程第 5 章](https://llvm.org/docs/tutorial/MyFirstLanguageFrontend/LangImpl05.html)，用于基本块、条件分支、汇合与回边的概念参考。本项目的 `while` 与严格 bool 条件为自定义教学语义，没有复刻教程的语言语法或 SSA / φ 实现。本次扩展没有重新抓取电子书。

数据流概念同日补充核对 [Cornell CS 4120 讲义](https://www.cs.cornell.edu/courses/cs4120/2026sp/notes/)的数据流方程与活跃性，以及 [LLVM 条件常量传播](https://llvm.org/docs/Passes.html#sccp-sparse-conditional-constant-propagation)的思想。实现未直接复制作者代码，仍不访问原书站点。

**应用运行、构建、单元测试均不访问电子书站点**。没有嵌入式原文 iframe、远程图片、字体或统计。用户主动点击原文链接后才会访问原站。

可选的单页参考缓存工具，默认不执行：

```sh
npm run sources:fetch                         # 仅显示用法，不请求网络
npm run sources:fetch -- --chapter 02         # 优先复用本地缓存
npm run sources:fetch -- --chapter 02 --refresh
```

- 一次只选一页，没有全书批量下载入口；进程锁避免本机多个抓取进程并发。
- 两次请求间隔至少 15 秒，状态跨进程保存在 `.cache/sources/`。
- 403 至少冷却 1 小时；429 至少冷却 15 分钟，并尊重更长的 `Retry-After`；网络错误和其他失败采用递增冷却。
- 失败后停止，不自动重试、不切换 IP、不绕过限制。记录的冷却超过 15 秒时直接退出，待用户之后手动重试。
- HTML 缓存与元数据只存本地、被 Git 忽略、不会打包进网站。已有书页可直接用于离线核对，无需反复下载。
- 该脚本只能协调本机调用，不能协调同一出口 IP 的其他设备或外部工具；15 秒不是原站保证的安全阈值，应以实际限流响应为准。
