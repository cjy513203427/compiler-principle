# 编译手记

基于宫文学《编译原理实战课》的中文交互笔记。参考同级 `transformer-animation` 的学习方式：**先预测，改输入，单步核对，再用自己的话复述**。本项目独立实现，不依赖兄弟项目运行。

## 本地运行

需要 Node.js 22.12+（或更新的受支持版本）和 npm。

```sh
npm ci
npm run dev
```

打开终端显示的地址（默认 `http://127.0.0.1:5173`）。所有编译与执行发生在浏览器中，无后端、账号或 API Key。仅在本仓库交付，没有创建云资源或发布网站。

```sh
npm run check       # 类型检查、算法与状态测试、生产构建
npm run test:e2e    # 桌面与手机尺寸的浏览器测试，需要本机 Chrome
npm run preview    # 本地预览生产构建
```

浏览器测试使用 Chrome channel；未安装 Chrome 时，可安装 Chrome，或在 `playwright.config.ts` 移除 `channel` 并安装 Playwright Chromium。

## 教学语言

```c
int result = 2 + 3 * 4;
print(result);

int x = 10;
{
  int x = 20; // 内层声明遮蔽外层
  print(x);
}
print(x);
```

支持 `int`、`bool`，变量声明和赋值，`+ - * /`、一元负号、括号、语句块、`print`、`//` 单行注释。语句需要半角分号。只有 ASCII 标识符；`int`、`bool`、`print`、`true`、`false` 是保留字。

整数使用 JavaScript 安全整数，除法向零取整，溢出和除零报告运行时错误。无隐式类型转换。初始化表达式先分析，新绑定随后引入；同层不能重复声明，内层允许遮蔽。源码限制 2000 字符，括号/一元运算/语句块嵌套限制 64 层。

支持 `if / else` 和 `while`，条件必须是 `bool`，主体必须用花括号。比较运算支持 `< <= > >= == !=`，算术优先于比较、比较优先于相等性。大小比较仅用于整数，相等性比较要求两侧类型相同。暂不支持 `break / continue`、逻辑短路、函数、字符串、浮点、闭包、对象与垃圾回收。IR 与字节码均为自定义教学格式，**不是 LLVM IR、JVM 或 CPython 的真实指令**，没有寄存器分配或机器码生成。

```c
int i = 1;
int sum = 0;
while (i < 4) {
  sum = sum + i;
  i = i + 1;
}
if (sum == 6) {
  print(sum);
} else {
  print(0);
}
```

第七个实验 `/?lab=cfg` 从原始 IR 划分基本块，再由虚拟机的真实执行快照生成按块回放的路径。图保留全部可能边，高亮本次实际经过的边；点击块可检查完整指令，前进/回退时变量与输出随快照更新。跳转使用生成的标签地址，不是写死的动画路线。

每次回放最多执行 2000 条字节码，避免错误循环阻塞界面。达到上限时明确显示暂停，**不代表已经证明程序不会终止**，暂停前的输出也不能用于判断完整行为等价。

## 算法与数据流

```text
source → tokenize → parse → analyze → generateIR → optimize → generateBytecode → execute
           tokens     AST     绑定/类型     TAC          TAC          栈式指令        快照
```

计算逻辑与 UI 分离，不使用 `eval` 或 `Function` 执行输入。每步状态来自真实扫描、构树、分析或执行。AST 回放展示最终树并高亮当时构建的节点，不伪装成增量生成的树。

直线代码沿用顺序传播与反向清理；**分支/循环已接入跨块优化**：先求解条件常量事实，再传播、折叠，最后依据可执行边删除不可达块，并在改写后的 CFG 上迭代活跃性，清理无用复制和标签。可能报错的未折叠算术仍然保留，输出与异常顺序不重排。三个开关分别控制表达式折叠、常量替换、分支/不可达与无用写入清理；分析本身不依赖开关，也不借用一次执行的结果。

第八个实验 `/?lab=dataflow` 展示原始 CFG 的分析：每次处理一个块，合并可执行前驱的 OUT，求出本块 IN / OUT，直到事实和边都不再变化。⊥ 是尚无信息，常量 c 是确定值，⊤ 表示不能确定唯一常量。循环可能让早期常量变成 ⊤；两条路径都赋 7 时仍可合并为 7。最后一步可选择任意块查看完整事实，也可查看原始结构图上的保守活跃变量集合。分析与执行快照清楚区分。

条件常量传播与活跃性均最多 200 轮；常量分析未收敛时保留原始 IR，不把未分析路径当成不可达。分析中间回放最多保留 240 次块处理，最终表始终展示完整分析结果，达到记录上限不会提前停止求解。实现为可变变量上的**稠密条件常量传播**，没有 SSA、φ、取值范围分析、循环展开或 LLVM 的稀疏实现。

页面实际运行原始版和优化版，比较当前程序的输出与错误；任一版本达到 VM 回放上限时，比较结果为无法判定。这个对照不等于一般性的语义等价证明，IR 指令数也不等于运行时间。

第九个实验 `/?lab=dominance` 从原始 CFG 的全部结构边求解支配集合，逐轮展示前驱交集与候选移除。完成后可查询 A 是否支配 B；若不支配，显示一条避开 A 的结构路径。直接支配树、自然循环的 header / latch / preheader / exit block、循环嵌套与支配边界都来自分析结果，不借用 VM 执行路径，也不按节点的绘图位置判断回边。

φ 面板按变量定义块计算**迭代支配边界的候选位置**，没有活跃性裁剪，所以可能多余；不生成版本名，不改写 IR 或执行候选 φ，尚未实现完整 SSA。自然循环识别不等于枚举所有有向环或不可约区域。支配分析最多 200 轮，未收敛不发布后续结论；仅截断前 240 次块处理的回放，最终集合仍完整。结构可达与绕行路径不代表路径上的条件可同时成立。

## 正则与自动机

第十个实验 `/?lab=automata` 对应原书第 02 讲“用两种方式构造有限自动机”的第二种方式：只写词法规则，自动生成扫描器。输入格式借用 flex 的 `%%` 分隔：

```text
Int: int
Id: [a-zA-Z][a-zA-Z0-9]*
Num: [0-9]+
skip: [ \t\n]+
%%
int intA 42
```

`%%` 上方每行一条“名称: 正则”，越靠前优先级越高；名为 `skip` 的规则匹配后丢弃；`%%` 下方都是待扫描的输入。这个实验使用自己的输入，不经过 Mini C 编译；切换到其他实验时，原来的 Mini C 程序会保留。

回放分三段，每一步都来自 `src/compiler/automata.ts` 的真实计算：

1. **正则 → NFA**：按原书图 7–11 的拼接规则逐个子表达式构造。连接时把前一段的结束状态与后一段的开始状态合并；`* + ?` 和 `|` 用 ε 边。清单采用原书 `0 ε -> 2` 的写法。
2. **子集构造**：先求 ε-闭包，把全部边上的字符集切成互不相交的输入类，再逐个 DFA 状态求 move 与闭包。一个 DFA 状态同时含多条规则的接受状态时，取排在前面的规则；完全胜不出的规则和能匹配空串的规则会被标出。
3. **最长匹配扫描**：一直读到 DFA 无路可走，再回到最近的接受位置生成 Token，并显示退回的字符数。空词素不会成为 Token。

最后一步可以查看 DFA 图（键盘可选状态）、DFA 状态表、NFA 清单和“NFA 回溯对照”。回溯对照参照原书 `matchWithNFA` 的过程，按建边顺序深度优先做整串匹配，并列出每次尝试的状态和位置。它与 DFA 选出的规则一致，代价却可能大很多，例如 `(a|aa)*b` 在 12 个 a 上要尝试 4000 多次。

支持字符、`[ ]` 字符集与区间、`[^ ]`、`.`（除换行）、`\d \w \s`、`\n \t \r`、`| * + ?` 和括号；正则中的空格只用于排版。字母表限于 ASCII 可打印字符与 `\t \n \r`。不做 DFA 最小化，不支持 `{m,n}`、锚点、捕获组和反向引用。限制为：最多 8 条规则，每条 80 字符，输入 300 字符；NFA 300 个状态，DFA 64 个状态。DFA 超限时停止构造，不发布扫描结果。扫描回放记录前 1500 步，Token 结果始终完整。回溯每个 Token 最多尝试 5000 次，只显示前 240 次。

单元测试用 JS `RegExp` 加暴力最长匹配作为独立对照，检查全部预设和额外用例的 Token 与报错位置。原书未展开子集构造，只推荐龙书第 2 版 3.7.1 节（纸质书，未在线核对）。2026-11-18 另核对 [Russ Cox 关于 Thompson NFA、回溯与 DFA 的文章](https://swtch.com/~rsc/regexp/regexp1.html)。

2026-11-17 核对 [Cornell 支配关系与 SSA 讲义](https://courses.cs.cornell.edu/courses/cs4120/2026sp/notes/reachdef/index.html)与 [LLVM 循环术语](https://llvm.org/docs/LoopTerminology.html)。新增实验沿用现有笔记、JSON 导入/导出和分享；旧版笔记兼容。本次扩展没有请求电子书站点。
